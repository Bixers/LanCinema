# Native iOS design

Mode: Operate in the library and connection settings; Experience during playback.

Use UIKit navigation, flat file lists, SF Symbols, semantic system colors, system Dynamic Type and standard back gestures. Browser follows the device's light/dark appearance. Playback remains black for video letterboxing with legible dark controls. Teal is the single interaction accent; playback uses its brighter mint variant for contrast.

Library and nested folders use inline navigation titles with native sort, view and connection controls. Details is the default view; the optional icon view and the sort field/direction persist across folders and launches. Windows File Explorer informs file organization within UIKit: yellow folder symbols, teal video/document symbols and neutral subtitle symbols distinguish file kinds alongside their names and type labels. Details uses flat rows with inset separators; icons use an unboxed grid without separators.

Details prioritizes the full filename, followed by saved playback progress and the search result's parent path when present. Names and supporting labels wrap without a line cap, including uninterrupted mixed Chinese/English names; rows grow with content. Below 650 points of safe-area width, size, type and modified time sit beneath the file identity. At 650 points or more, outside accessibility text categories, the name takes the remaining width beside size (82 points), type (90 points) and modified time (142 points), with 12-point gaps. Column headings share that wide alignment; compact details uses four equal-width sort controls. File rows have 12-point vertical padding. Icon view centers a larger symbol above each wrapping filename and type/size caption; equal-width columns use 16-point gaps, with the count calculated from safe-area width divided by 170 points, rounded down and limited to one through five.

The location header provides a wrapping shared-folder path, an ancestor menu and an up control, disabled at the root. Search remains recursive within the current subtree and includes a wrapping parent-path line to distinguish duplicate names. Sorting supports name, size, type and modified time in either direction, always keeping folders first. The selected detail heading shows a direction chevron; tapping it reverses direction. The native sort menu remains available in both views.

Accessibility text categories use a single icon column or stacked details with explicit size/type/modified labels, without fixed metadata columns or column-heading controls. Filenames and metadata retain Dynamic Type sizing and unlimited wrapping. The location button uses the short visible label “文件夹路径” with a scaled font capped at 24 points to preserve browsing space; its accessibility value retains the full path and its menu retains ancestor navigation. Sorting stays available from the navigation bar. Layout changes with safe-area width and text category, including rotation; large text scrolls vertically rather than clipping names.

Controls stay inside safe areas, including landscape. Targets are at least 44 points. Standard menu contains persistent speeds and a separate hold-speed setting. Holding the canvas for 350 ms activates the temporary speed; release, cancellation, app interruption and dismissal restore the selected speed. Seeking and buttons have separate touch regions.

Landscape playback uses a single compact bottom row for skip, play, elapsed/total time, slider, speed, and tracks. Buttons retain 48-point targets; the row uses 4-point vertical padding. The status bar stays hidden in landscape. Both bars sit at safe-area edges, with a dark translucent backing for contrast. Portrait retains the stacked timeline and buttons. Rotation reuses the same controls without reopening playback. Paused status text hides with the bars; EOF retains duration and seeking, with a replay control and a brief hint explaining drag-to-review.

No hero marketing layout, display web fonts, decorative gradients, poster placeholders, or web UI wrappers. Captures must come from the built iOS simulator; browser mockups are not evidence of native rendering.

Connection extends the native visual system: a scrollable form with persistent Password / QR segments, labeled address and password fields, visibility toggle, inline failures, and a primary Connect action. Bonjour discovery never broadcasts credentials. Scanning uses the native camera or a system photo picker.

Desktop settings use a restrained light surface, teal primary action, system Chinese typography, labeled inputs, a wrapping shared-directory list with Add folder and Remove selected controls, a single Save and apply button, and a connection QR panel. Folders can be added across volumes; removing an entry only unshares it after saving. Empty lists explain how to add a folder. Smaller windows scroll instead of overlapping controls. Closing keeps the tray service alive; an explicit tray command stops it. Save failures preserve editable fields and report recovery.

Playback adds a 48-point display-mode control beside the title, retaining safe-area controls and native action sheets. Default smart fit preserves the effective picture after local border analysis. The action sheet explains smart fit, explicit crop-to-fill (may lose edges), and full-frame (retains original borders). The display button exposes the current saved mode to accessibility. Video cropping uses the renderer with an unscaled viewport; subtitles must remain readable in all modes. Full-frame bypasses border analysis.

Playback input lives on a transparent surface above the VLC drawable and below the controls. A tap toggles both bars; playing without input hides them after four seconds. A horizontal pan previews the target and signed time difference in a centered dark overlay, committing only on release. A full-width drag covers 30–120 seconds depending on duration, bounded to the media timeline. Vertical pans do not seek. Holding still activates temporary speed; moving horizontally before the hold threshold seeks instead. Paused seeks retain their requested time until VLC acknowledges the clock; resuming is validated against advancing decoder time. Cancelled gestures discard the preview. The standard slider and buttons remain available alongside gestures.
