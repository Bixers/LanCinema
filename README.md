# 局域影院 · iOS 1.9.3 / 电脑端 1.5.1

Windows 电脑文件夹的 iPhone 浏览与播放客户端。默认共享 `G:\123`，可在电脑端添加多个文件夹，支持跨盘符。支持嵌套目录、递归搜索、长名称换行、VLC 多格式播放、进度记忆、0.5～3 倍速和长按临时倍速。

iOS 1.9.3 / build 22 调整播放方向：竖屏视频始终保持竖屏，不随手机转动；横屏视频继续遵循「播放时自动横屏」开关。判断使用视频原始显示比例，考虑像素宽高比和 90°／270° 旋转标记，不受铺满或黑边裁切影响。读取到视频尺寸前保持竖屏，避免竖屏视频进入时先横转。退出仍恢复竖屏；只需更新 IPA，电脑端继续使用 1.5.1。

1.9.3 的 [GitHub Actions 验证](https://github.com/Bixers/LanCinema/actions/runs/45106313655)通过 5 项 UI 场景及 36 项单元／音频测试（源码 `955bd6762bbdaefd75f3922bfb1d4051168ef497`）。iPhone 17 Pro / iOS 26.5 模拟器覆盖普通竖屏、带 90° 旋转矩阵的竖屏视频、两种开关状态、左右横拿手机、拖动后实际帧推进、切后台返回，以及原横屏开关和大字号设置页。几何单元测试另外覆盖像素宽高比、转置和未知尺寸回退。未在实体 iPhone 安装验证此版本。

iOS 1.9.2 / build 21 增加「设置 → 播放时自动横屏」，默认开启。文件库、收藏、继续观看和设置保持竖屏；进入视频自动横屏，退出恢复竖屏。关闭后播放器跟随手机方向，其他页面仍保持竖屏。开关自动保存在当前手机，不随电脑或共享目录切换；原有收藏、观看进度和同步设置继续沿用。只需更新 IPA，电脑端继续使用 1.5.1。

1.9.2 已在 iPhone 17 Pro / iOS 26.5 模拟器分批验证 10 项 UI 场景及 33 项单元／音频测试。[完整回归](https://github.com/Bixers/LanCinema/actions/runs/44877843226)中 8 项 UI 与 33 项单元测试通过，2 项 UI 因旋转过渡时测试点击过早失败；修正测试等待后[两项定向复测通过](https://github.com/Bixers/LanCinema/actions/runs/44879617209)。最终仅调整设置说明的辅助功能字号和自动高度，[设置页复测通过](https://github.com/Bixers/LanCinema/actions/runs/44880040122)，其余播放生产代码与完整回归相同。覆盖进入／退出方向、继续观看、后台返回、开关重启保存、手动旋转、实际视频帧推进及最大辅助功能字号。未在实体 iPhone 安装验证此版本。

iOS 1.7.0 / build 17 增加“继续观看”和播放诊断，优化拖动后的恢复。

- 文件库底部“继续观看”集中显示未看完的视频，按最近观看排序，显示进度、时间和所在目录；左滑或编辑可移除记录，不删除电脑文件。记录仅保存在此手机，按电脑地址及共享目录集合区分，最多 100 项。旧版单文件进度仍可续播，在再次播放后进入集中列表。
- 每五秒、暂停、切到后台或关闭时保存已实际显示的视频位置；播完自动移除。选择历史项前检查文件是否仍存在；同路径文件的大小、修改时间或封面版本改变时从头开始。临时断网保留记录。
- 拖动以画面帧确认目标，连续操作以最后一次为准。前台需要播放时，约八秒未恢复会重新打开一次输入；该次恢复约十二秒仍失败则停止自动重试，保留最后确认的位置。持续播放中十二秒没有新画面也会尝试一次恢复。暂停、后台及音频中断不消耗恢复等待预算。
- 正常拖动保留现有 AVAudioEngine 输出，只丢弃旧位置的音频；故障恢复和播放结束后回看会在后台串行等待旧输入停止，再重新打开，避免旧回调与新播放混在一起。
- 播放器右上角“…”打开诊断，可检查连接和 HTTP 分段读取、重新打开视频，或通过系统分享导出本次报告。报告只含系统版本、状态、时间、解码及显示计数等，不含密码、电脑地址、文件名或路径。最多保留本次会话的 160 个事件，不自动上传。

原生音频回归检查音频解码、视频输出帧和时间推进，覆盖打开、拖动、暂停恢复、倍速、中断、续播、EOF 回看、校准和试看切换。这不等于测得扬声器真实出声时间或物理音画偏差；需使用合成闪光／提示音素材在实际手机、耳机上核对。

1.2.2 / build 7：修复 TS 拖动后花屏、卡住，以及重新进入后仍卡住。**必须同时更新电脑端 EXE 和 IPA。** 首次打开 `.ts`、`.mts`、`.m2ts` 时，电脑在本地将音视频流无损封装为带关键帧索引的 MKV 缓存，完成后手机播放缓存。没有重新编码，不改变画质，也不修改原文件。后续打开相同文件复用缓存。取消强制 avformat 解析和软件解码，使用播放器的 Matroska 解析和默认解码路径。

缓存位于 `%LOCALAPPDATA%\LanCinema\playback-cache`，每部视频通常需要接近原文件大小的额外空间。一次只准备一部视频，首次打开大文件需等待完整封装；磁盘空间不足时会提示。超过 8 GiB 后，在准备下一部视频时尝试清理至少 6 小时未访问的旧缓存，因此 8 GiB 是软目标而非硬上限。退出电脑服务后可手动删除缓存目录，之后会重新生成。个别无法装入 MKV 的内嵌字幕会被省略，并在音轨/字幕菜单提示；可用外挂字幕。

新版忽略旧版 TS 续播记录，升级后首次从头播放。以后只保存播放器已经输出视频帧的位置，不保存尚未恢复画面的跳转目标。“字幕和音轨”菜单提供“从头重新播放”。

TS 回归素材包含非零起始时间戳、10 秒间隔的关键帧。测试同时检查索引跳转帧与顺序解码帧一致，并比较模拟器连续截图，要求两帧中央区域的彩色覆盖均超过 80%，且像素明显变化超过 2.5%，用于排除仅时钟推进、大片灰色损坏或冻结的情况。

build 5 增加画面横向拖动调节进度：右滑快进、左滑后退，滑动时显示目标时间，松手后跳转；暂停和上下栏隐藏时也能操作。纵向滑动不调节进度。单击画面隐藏/唤起上下栏，播放中无操作约 4 秒自动隐藏；长按画面仍为临时倍速。拖动取消不提交跳转，进后台会清理手势状态。

## 使用

1. 首次升级先按 [SYNC.md](SYNC.md) 备份并核对旧记录。从托盘退出旧服务后运行 `LanCinema-PC-1.5.1.exe`，点击“添加文件夹…”添加一个或多个共享目录（支持跨盘符），设置至少 8 位连接密码，点击“保存并应用”。设置保存到 `%LOCALAPPDATA%\LanCinema\settings.json`，密码使用 Windows DPAPI 加密。
2. “登录 Windows 后自动启动”可开关；默认开启。关闭窗口后在托盘继续运行；右键托盘图标可退出。修改 EXE 所在位置后，请重新打开并保存设置以更新自启路径。
3. 手机和电脑在同一局域网。App 可自动发现电脑并输入密码连接，或扫描电脑端二维码（也支持从相册识别）。发现受阻时可手动填写电脑端显示的 IPv4 地址。固定端口 8123。允许 App 使用本地网络；相机权限仅用于扫码。
4. 手机连接成功后保存地址，密码放入 iOS 钥匙串。修改共享目录后返回文件库首页并刷新；修改电脑密码后需重新连接。
5. 播放默认“智能适配”：电脑在多个时间点抽样识别内嵌黑边，App 去黑边后按原比例显示有效画面。右上角“画面显示方式”提供“智能适配”“裁切铺满”“完整显示”，选择及倍速设置自动保存。比例不匹配时智能适配会保留必要留边；严格铺满请选择裁切铺满，画面边缘可能被裁掉。分析失败不影响播放。

电脑关闭、休眠或退出服务时不能继续访问。视频不转码，经局域网 HTTP 传输；自动黑边检测仅在本地解码少量帧，不上传视频。

## 全部视频与随机试看（1.10.0）

- 文件库底栏「全部视频」汇总所有共享盘符和嵌套文件夹的视频，大封面浏览，不移动文件。长按结果可打开所在文件夹或加入收藏。保留原来的详细信息／图标式文件夹浏览。
- 新视频库支持按文件名、大小、修改时间排序；搜索同时匹配完整共享路径和文件名，多个关键词用空格分隔，要求全部匹配。原文件夹递归搜索也支持这套规则。搜索历史最多 10 条，按电脑和共享目录保存在手机，可清空。
- 「随机试看」从当前搜索结果抽取；没有搜索时从全部视频抽取。每轮洗牌，抽完前不重复；单个结果时仍是同一部。无效视频可直接换一部。
- 选中视频后，电脑单线程解码音轨为 8 kHz 单声道，每 0.5 秒计算 RMS，评估连续约 30 秒窗口。评分权重为持续相对音量 60%、有效声音占比 25%、声音变化 15%；音量按本片分位数归一化并截断过强峰值，降低孤立爆音影响。先播放最高分候选，另选最多两段，优先不重叠；短视频可部分重叠，但起点至少相隔 15 秒。评分仅表示本片的声音活跃程度，音乐、对白、噪声都可能得高分，不表示内容精彩或受欢迎，也没有画面语义／语音识别。
- 无音轨、静音、声音过于均匀、短于 36 秒、超过 6 小时或分析超时时，退回按时长分散抽样；35 秒以内可只提供一段。「字幕和音轨」菜单显示当前选段依据及声音评分。片段不重新编码、不生成视频副本。
- 「换一段」切换同一部的另一片段；「换一部」先安全停止旧输入再抽取下一部；「看全片」从当前播放处继续，播放中的输入和时钟不重建。试看进度限制在所选片段内，结束后保留操作入口。试看不写入或删除原有观看记录，转入全片后才正常记进度。
- 电脑端需更新到 1.6.0。目录索引首次使用时在单一后台线程读取文件元数据，60 秒过期后更新，也可下拉刷新；封面沿用按需加载和缓存。只分析选中的试看视频，一次一个，Windows 下以低于正常的进程优先级运行；时长探测最多 10 秒，音频分析最多 45 秒，随后回退抽样。分析发生在试看开始之前，不在手机播放线程中执行。最多 256 条内存结果和 1000 条电脑 JSON 缓存，位于 `%LOCALAPPDATA%\LanCinema\preview-cache`；按原文件路径、大小、修改时间及算法版本失效。JSON 只保存时长、片段起止时间和评分，不保存音频、字幕或转录内容。TS 仍先复用／生成原有无损索引。
- 暂未加入自定义别名、时长／分辨率组合筛选、合集拼图、首次发现日期和已看完分类。大封面会显示已有续播记录的位置和总时长；未播放文件不批量探测时长。

评分未完成时退出、换片或转入全片，会向电脑发送取消请求，终止对应音频分析，不保存取消产生的失败结果。网络断开时取消通知可能无法送达，后台分析仍受 45 秒超时限制。已在进行的 TS 无损索引沿用原缓存流程。
