# 局域影院 · iOS 1.8.0 / 电脑端 1.4.2

Windows 电脑文件夹的 iPhone 浏览与播放客户端。默认共享 `G:\123`，可在电脑端添加多个文件夹，支持跨盘符。支持嵌套目录、递归搜索、长名称换行、VLC 多格式播放、进度记忆、0.5～3 倍速和长按临时倍速。

iOS 1.8.0 / build 18 新增收藏。**本次只需更新 IPA，电脑端继续使用 1.4.2。** 在详细信息、图标视图或递归搜索结果中，长按视频或文件夹，选择“加入收藏”；再次长按可取消。文件库底部“收藏”集中显示已保存项目，最近收藏在前，保留实际视频封面、完整名称及所在路径，点选可播放或进入文件夹。列表左滑或“编辑”可取消收藏，不删除原文件，也不影响观看进度。

收藏仅保存在此手机，退出或重启后保留；按电脑地址和共享目录集合区分，同名但不同路径的文件可分别收藏，没有观看记录的 100 项自动淘汰限制。打开前检查项目是否可访问，电脑离线或密码失效时保留收藏，文件移动、删除或共享目录改变时提供处理提示。收藏按路径定位；同路径替换文件后打开该路径的现有文件。更改电脑地址或共享目录集合后显示对应列表。

iOS 1.7.0 / build 17 增加“继续观看”和播放诊断，优化拖动后的恢复。

- 文件库底部“继续观看”集中显示未看完的视频，按最近观看排序，显示进度、时间和所在目录；左滑或编辑可移除记录，不删除电脑文件。记录仅保存在此手机，按电脑地址及共享目录集合区分，最多 100 项。旧版单文件进度仍可续播，在再次播放后进入集中列表。
- 每五秒、暂停、切到后台或关闭时保存已实际显示的视频位置；播完自动移除。选择历史项前检查文件是否仍存在；同路径文件的大小、修改时间或封面版本改变时从头开始。临时断网保留记录。
- 拖动以画面帧确认目标，连续操作以最后一次为准。前台需要播放时，约八秒未恢复会重新打开一次输入；该次恢复约十二秒仍失败则停止自动重试，保留最后确认的位置。持续播放中十二秒没有新画面也会尝试一次恢复。暂停、后台及音频中断不消耗恢复等待预算。
- 正常拖动保留现有 AVAudioEngine 输出，只丢弃旧位置的音频；故障恢复和播放结束后回看会在后台串行等待旧输入停止，再重新打开，避免旧回调与新播放混在一起。
- 播放器右上角“…”打开诊断，可检查连接和 HTTP 分段读取、重新打开视频，或通过系统分享导出本次报告。报告只含系统版本、状态、时间、解码及显示计数等，不含密码、电脑地址、文件名或路径。最多保留本次会话的 160 个事件，不自动上传。

iOS 1.6.1 / build 16 与电脑端 1.4.2 补齐视频缩略图：图标视图显示视频中的真实画面，详细信息显示小预览。图片保持比例，名称继续完整换行；无法取帧时保留视频图标，不阻止打开文件。仅为可见项目请求封面，离开时取消，最多两路请求；电脑端复用内置 FFmpeg 本地取帧，独立磁盘缓存随文件大小或修改时间变化而失效，不更改原视频。**请同时更新 EXE 和 IPA**：从电脑托盘退出旧服务后运行新版，点击“保存并应用”更新自启路径，手机返回文件库刷新。共享目录、密码和原设置保留。

封面缓存位于 `%LOCALAPPDATA%\LanCinema\thumbnails`，最多约 128 MiB 或 2000 张，按最近使用清理。手机使用最多约 16 MiB / 200 项的内存缓存，不把封面或密码写入系统 URL 磁盘缓存。首次浏览会先显示文件图标，完成取帧后出现图片。损坏或当前解码器不支持的视频可能无法显示缩略图，仍可尝试播放。

iOS 1.6.0 / build 15 将文件库调整为资源管理器式浏览：默认“详细信息”，可从右上角切换“图标”。详细信息显示名称、大小、类型和修改时间；竖屏先完整显示文件名，再显示元数据，横屏按列对齐。列标题可点击排序，再次点击反向；原排序菜单保留，文件夹始终优先。黄色文件夹和视频、字幕图标方便识别；名称不限行数。路径菜单可跳转祖先目录，向上箭头返回父文件夹，视图和排序自动保存。辅助大字体下图标视图改为单列。搜索仍覆盖当前目录及所有子目录，并显示结果所在位置。**只需更新 IPA，电脑端继续使用 1.4.1。**

iOS 1.5.1 / build 14 修复名称中含 `+` 时无法浏览或播放的问题：HTTP 查询参数现在将字面加号编码为 `%2B`，避免电脑端将其解析为空格。修复覆盖目录、视频、外挂字幕、搜索词和连接密码，并在追加 TS 缓存标志或搜索参数后保持正确编码。文件不需要改名、转码或重新封装。只需更新 IPA，电脑端继续使用 1.4.1。

iOS 1.5.0 / build 13 优化播放器横屏与结束回看：横屏将进度、时间、播放和音轨控制合并为单行底栏，保留 48 点按钮；隐藏系统状态栏，上下栏贴近安全区域边缘。播放结束后保留时长与可操作进度条，可以拖动进度、横向滑动画面、后退十秒回看，或点击“重新播放”。回看会重新建立 VLC 输入并直接打开到目标时间，保留倍速、显示方式和已选字幕/音轨。暂停时收起控件会一起隐藏中央暂停提示，收起控件时允许系统自动隐藏 Home 指示条。**本次只需更新 IPA；电脑端继续使用 1.4.1。**

关闭播放器时，在后台等待底层解码停止后再释放画面与音频对象，避免异步停止尚未完成时提前释放回调目标。

电脑端 1.4.1 支持多个共享目录：点击“添加文件夹…”逐个选择任意盘符的文件夹，点击“保存并应用”后持久保存。只有一个目录时维持原浏览方式；多个目录时手机文件库首页显示独立入口，包含盘符，同名入口自动区分。首页搜索覆盖全部共享目录；进入目录后仅搜索当前目录及子目录。移除所选仅取消共享，不删除文件。旧配置自动迁移，默认仍为 `G:\123`，密码、自启设置保留。手机 1.4.0 及以上版本支持多目录共享。从托盘退出旧电脑端后运行新版；若 EXE 路径改变，点击保存以更新自启路径。手机返回文件库首页并下拉刷新。

已验证 Windows 跨 C/G 盘符读取、多目录递归搜索、字幕、HTTP Range、TS 准备与裁切接口路由、配置重启恢复和同名目录区分。41 项测试中 40 项通过、1 项符号链接测试因系统权限跳过；新版界面在常规和较小窗口下均检查，较小窗口可滚动。目录数量或集合改变会切换文件库标识；原播放进度不会跨不同共享集合复用。重新启动时需确保配置中的磁盘和目录可访问。

1.4.0 / build 12 优化画面适配：默认“智能适配”仅去除检测到的黑边，保留有效画面比例；也可选择“裁切铺满”或“完整显示”。使用播放器内部裁切，不再整体放大 UIView。暂停切换会刷新一帧并保持暂停；黑边分析和裁切设置在视频已输出画面后开始，避免影响启动。电脑端抽样检测开头、35% 和 70% 三个位置；证据不足、超时或旋转视频安全回退。**请同时更新 IPA 与 EXE**。旧版主动选择的“完整显示”保留，原默认铺满升级为智能适配，后续选择自动保存。

1.3.1 / build 11 修复 UTF-8 中文字幕显示方框：随 App 内置 Noto Sans CJK SC 字体，并明确指定给 VLC/FreeType 字幕渲染器。字体支持简繁中文、日文和韩文，按 SIL Open Font License 1.1 分发。该次更新只涉及 IPA。

外挂字幕：将 UTF-8 编码的 SRT 放在视频同目录，播放时打开“字幕和音轨”，选择“外挂 · 字幕文件名”。不要求同名，需手动选择；修改字幕后退出视频再重新打开。当前不提供字幕编码切换。

1.3.0 / build 10 增加文件排序：文件库右上角可按文件名、大小、修改时间或类型排序，并选择升序/降序。文件名采用自然排序；文件夹始终在前，按大小或类型排序时文件夹之间按名称排列，不计算文件夹总大小。选择自动保存，适用于目录浏览和当前目录下的递归搜索结果。**请同时更新电脑 EXE 与 IPA**，新版电脑端提供修改时间；旧电脑端仍支持其他排序。

针对打开、前后拖动和续播时短暂无声，VLC 继续负责解码、音轨选择和倍速，16 位 PCM 改由持续运行的 AVAudioEngine 输出。暂停保留已排队声音，跳转清理旧位置 PCM。当前输出为 48 kHz 双声道；初始化失败时保留 VLC 默认输出。局域网缓冲设为 300 ms，续播在启动前指定保存位置，倍速仅在数值变化时提交。系统音频中断结束后遵循系统恢复许可，主动暂停的视频不自动恢复。

音频回归测试从生产 AVAudioEngine 混音器采集实际非静音样本，覆盖打开、前后跳转、暂停恢复、暂停时跳转、两倍速、系统中断和续播。探针只在 Debug 测试启用。模拟器结果不能代替真机扬声器、蓝牙路由及长时间音画同步验证。

1.2.2 / build 7：修复 TS 拖动后花屏、卡住，以及重新进入后仍卡住。**必须同时更新电脑端 EXE 和 IPA。** 首次打开 `.ts`、`.mts`、`.m2ts` 时，电脑在本地将音视频流无损封装为带关键帧索引的 MKV 缓存，完成后手机播放缓存。没有重新编码，不改变画质，也不修改原文件。后续打开相同文件复用缓存。取消强制 avformat 解析和软件解码，使用播放器的 Matroska 解析和默认解码路径。

缓存位于 `%LOCALAPPDATA%\LanCinema\playback-cache`，每部视频通常需要接近原文件大小的额外空间。一次只准备一部视频，首次打开大文件需等待完整封装；磁盘空间不足时会提示。超过 8 GiB 后，在准备下一部视频时尝试清理至少 6 小时未访问的旧缓存，因此 8 GiB 是软目标而非硬上限。退出电脑服务后可手动删除缓存目录，之后会重新生成。个别无法装入 MKV 的内嵌字幕会被省略，并在音轨/字幕菜单提示；可用外挂字幕。

新版忽略旧版 TS 续播记录，升级后首次从头播放。以后只保存播放器已经输出视频帧的位置，不保存尚未恢复画面的跳转目标。“字幕和音轨”菜单提供“从头重新播放”。

TS 回归素材包含非零起始时间戳、10 秒间隔的关键帧。测试同时检查索引跳转帧与顺序解码帧一致，并比较模拟器连续截图，要求两帧中央区域的彩色覆盖均超过 80%，且像素明显变化超过 2.5%，用于排除仅时钟推进、大片灰色损坏或冻结的情况。

build 5 增加画面横向拖动调节进度：右滑快进、左滑后退，滑动时显示目标时间，松手后跳转；暂停和上下栏隐藏时也能操作。纵向滑动不调节进度。单击画面隐藏/唤起上下栏，播放中无操作约 4 秒自动隐藏；长按画面仍为临时倍速。拖动取消不提交跳转，进后台会清理手势状态。

## 使用

1. 从托盘退出旧服务后运行 `LanCinema-PC-1.4.2.exe`，点击“添加文件夹…”添加一个或多个共享目录（支持跨盘符），设置至少 8 位连接密码，点击“保存并应用”。设置保存到 `%LOCALAPPDATA%\LanCinema\settings.json`，密码使用 Windows DPAPI 加密。
2. “登录 Windows 后自动启动”可开关；默认开启。关闭窗口后在托盘继续运行；右键托盘图标可退出。修改 EXE 所在位置后，请重新打开并保存设置以更新自启路径。
3. 手机和电脑在同一局域网。App 可自动发现电脑并输入密码连接，或扫描电脑端二维码（也支持从相册识别）。发现受阻时可手动填写电脑端显示的 IPv4 地址。固定端口 8123。允许 App 使用本地网络；相机权限仅用于扫码。
4. 手机连接成功后保存地址，密码放入 iOS 钥匙串。修改共享目录后返回文件库首页并刷新；修改电脑密码后需重新连接。
5. 播放默认“智能适配”：电脑在多个时间点抽样识别内嵌黑边，App 去黑边后按原比例显示有效画面。右上角“画面显示方式”提供“智能适配”“裁切铺满”“完整显示”，选择及倍速设置自动保存。比例不匹配时智能适配会保留必要留边；严格铺满请选择裁切铺满，画面边缘可能被裁掉。分析失败不影响播放。

电脑关闭、休眠或退出服务时不能继续访问。视频不转码，经局域网 HTTP 传输；自动黑边检测仅在本地解码少量帧，不上传视频。

## 数据与依赖

服务只读共享目录及其子目录，拒绝路径越界；电脑密码和真实媒体不提交 GitHub。二维码包含地址和密码，勿公开分享。

播放器为 [VideoLAN VLCKit](https://github.com/videolan/vlckit)，许可见 `App/VLCKit-LICENSE.txt`。桌面依赖与源码位置见 `THIRD_PARTY.md`。

本仓库从经过检查的源码快照创建，不包含原开发仓库历史。测试目录里的视频均为合成画面，测试连接密码仅用于本地回归测试。

黑边检测是保守抽样，不代表整部影片逐帧验证；不足 9 秒、无法读取时长或带旋转元数据的视频暂不自动去黑边。画幅发生变化而被误裁时可随时切换“完整显示”。原始媒体文件不会被修改。
